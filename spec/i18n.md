Interpolation: numbers via `Number.toLocaleString(locale)`; `{file}` = file
name as-is; `{query}` = query truncated to 60 chars + ellipsis if longer;
`{detail}` = English parser error detail, **not** translated (keeps errors
stable and greppable).

## 3. Translation quality rules (executed in CHECKLIST 4.1)

1. Translate all 20 non-EN locales from the EN column — one pass per locale,
   preserving `{slot}` tokens exactly (same name, same position class).
2. Keep tone: short UI phrasing, no marketing fluff. Buttons ≤ 2 words where
   the language allows.
3. `err.*` values must start with the same `✕` character in every locale.
4. Never translate: "SimpleLogSearch", "AND/OR/NOT", filenames, `{detail}`.
5. Back-translation spot check: 5 random keys × 3 locales (ar, zh-CN, ja)
   re-translated to EN by the LLM and compared for meaning drift; record
   result in Session Log.
6. Any string that cannot be translated well in a target language: keep a
   faithful short version — do not fall back to English silently.

## 4. Runtime behavior

- `apply(locale)`: sets every element carrying a `data-i18n`,
  `data-i18n-aria` or `data-i18n-placeholder` attribute (select as an explicit
  selector list — an attribute-NAME wildcard like `[data-i18n*]` is not valid
  CSS and throws in real browsers), `<html lang>` and
  `<html dir>` (ar/ur → rtl, all others ltr), persists
  `localStorage.setItem("sls-lang", locale)`.
- Boot: inline `<head>` script (3 lines, before CSS paint) reads
  `localStorage["sls-lang"]`, validates against the known code list, sets
  `lang`/`dir` on `<html>` immediately → no flash of wrong language/direction.
  Full string application happens in `app.js` init.
- Default = `en`. Unknown/stale stored value → `en`.
- RTL: all CSS uses **logical properties** (`margin-inline-start`,
  `inset-inline-end`, text-align: start …) so the header row, error slot and
  buttons mirror automatically for ar/ur. Verify visually in M4 (Arabic +
  Urdu pass).
- The `<select>` itself always shows endonyms regardless of active locale.
