About SimpleLogSearch

SimpleLogSearch is a free log file search that runs entirely in your browser. You upload a log, type an AND, OR, or NOT query, and read the matching lines with their original line numbers — all of it executed on your own machine. This page is the short version of who built it, why it exists, and how it works under the hood.

Why this tool exists

I search logs all the time as part of my cybersecurity work. I use advanced log parsing tools, but in practice I often find that Notepad++ and Ctrl+F do the job just fine. The moment a task needs more than one plain search string — combine two terms, exclude a known noiser, match an exact quoted phrase — ordinary find falls short, and heavy tooling is overkill. SimpleLogSearch sits exactly in that gap: a search box with real boolean syntax on top of an ordinary text window, private enough to point at whatever I am investigating.

I made this tool for myself first, and have now made it available to you. It is the same one I would use daily: no signup, no tiers, nothing attached.

Data safety

Your logs are never uploaded to a SimpleLogSearch server — there is no server. Everything stays in your browser: the file is read into page memory with the browser's own file API, the search runs locally on your machine, and everything is discarded when you close the page or load another file. I need it this way so that I can use this at work on logs I am not free to copy out of my environment; you can use it at work, too. No accounts means nothing to store, leak, or sell, and the only preference the app remembers is your interface language.

Design principles

Three principles drove the design. First, privacy-first client-side processing: the architecture makes uploading impossible rather than merely unlikely. Second, a familiar Google-style dark UI — a magnifier search bar on a dark gray canvas, responsive down to phone width, with no learning curve for anyone who has ever used a web search box. Third, agent-friendly by design: through WebMCP the page exposes four tools (get_log_status, search_logs, reset_view, load_sample_log) so an AI assistant in a supported browser can run searches on your behalf.

Under the hood

SimpleLogSearch is a static site written in vanilla JavaScript — no frameworks, no build step, no runtime dependencies. It is hosted on GitHub Pages, which keeps the entire operation to a few dollars of static hosting per year. The results window is virtualized: only the rows currently visible exist in the page, so a 10 MB file with 100,000 lines scrolls without stutter while a 50 MB upload cap keeps memory in check. Matching is case-insensitive substring, deliberately grep-like in being honest about exactly what it will and will not find.
