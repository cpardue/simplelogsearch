SimpleLogSearch

About SimpleLogSearch

A free log file search that runs entirely in your browser.

Why this tool exists

I search logs daily for my cybersecurity work. Ctrl+F handles one string; combine two terms, exclude a noiser, or match an exact phrase and ordinary find falls short while heavy tooling is overkill. SimpleLogSearch fills that gap.

I made it for myself first: no signup, no tiers, nothing attached.

Data safety

Your logs are never uploaded — there is no server. Files are read into page memory, searched locally, and discarded when you close the page. I need it this way to triage at work on logs I'm not free to copy out. No accounts means nothing to store, leak or sell.

Design principles

  • Privacy-first, client-side — uploading is impossible by architecture, not by promise.
  • Familiar Google-style dark UI — a search bar anyone has used, responsive to phone width.
  • Agent-friendly via WebMCP — an AI assistant in a supported browser can run searches on your behalf.

Under the hood

A static site in vanilla JavaScript — no frameworks, no build step — hosted on GitHub Pages. The results window is virtualized, so 100,000-line files scroll smoothly under the 50 MB cap; matching is case-insensitive substring, grep-like.
